# 数据结构和算法

数据结构和算法的作用：提升程序的性能
算法是为了解决实际问题而设计的，数据结构式算法需要处理问题的载体。

## 数据结构

存储、组织数据的方式，分为`线性结构`和`非线性结构`

内存中是以字节为基本存储单位的，每个基本存储空间都有自己的地址，整形（int） 4 个字节，字符(char) 1 个字节。

### 线性结构

数据结构中各个节点具有线性关系，特点：

1. 线性结构是非空集
2. 线性结构所有节点都最多只有一个直接前驱节点和一个直接后继节点

典型的线性结构：栈、队列等

#### 顺序表

    将元素顺序地放在一块连续的存储区里，元素间的顺序关系由他们的存储顺序自然表示。
    数据区：存储元素
    信息区：存储元素的个数、容量、偏移量等信息

    扩充的两种策略
    1. 每次扩充增加固定数目的存储位置。称为线性增长。
    2. 每次扩充容量加倍。称为指数增长。

    元素存储区的替换
    1. 一体式存储的顺序表存储在连续的空间，只能整体搬迁。
    2. 分离式存储的顺序表可只整体更换数据区，信息区的链接更新即可。

##### 一站式存储

数据区和信息区在一起，存储区是连续的。

##### 分离式存储

数据区和信息区分开存储，存储区是不连续的。
列表中数据大小不固定，偏移量也不确定。

#### 链表

将元素存放在通过连接构造起来的一系列存储块中，存储区是非连续的。

### 非线性结构

非线性结构就是数据结构中各个节点之间具有多个对应关系。特点：

1. 非线性结构是非空集
2. 非线性结构的一个节点可能有多个直接前驱节点和多个直接后继节点
   典型的非线性结构：树结构和图结构

## 算法

实现业务目的的各种方法和思路

五大特性：有输入、有输出、有穷性、确定性、可行性

### 时间复杂度

时间复杂度 T

主要条件：随着问题规模而变化的
次要条件：随着问题规模变化而不变的

On^2：主要条件是 n^2，次要条件是 1
T(n) = O(n^2)

#### 时间复杂度计算规则

1. 基本操作 O(1)
2. 顺序结构 T(n) = O(n)
3. 循环结构，复杂度按乘法计算
4. 分支结构，时间复杂度取最大值
5. 判断一个算法的效率时，往往只需要关注操作数量的最高次项，其他次要项和常数项可以忽略
6. 在没有特殊说明时，我们所分析的算法的时间复杂度都是指最坏时间复杂度

常见的时间复杂度
O(1) < O(logn) < O(n) < O(nlogn) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)

### 空间复杂度

在运算中临时占用存储空间大小的度量 S(n)

O(1)：普通常量、变量、对象、元素数量与输入数据大小 N 无关的集合，皆使用常数大小的空间。
O(n)：元素数量与 N 呈线性关系的任意类型集合（常见一维数组、链表等），均使用线性大小的空间。
O(n^2)：元素数量与 N 呈平方关系的任意类型集合，均使用平方大小的空间。
